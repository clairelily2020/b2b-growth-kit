# Workflow: event ABM

**Goal:** turn an upcoming trade show or conference into pre-booked conversations with the right exhibitors or attendees, and a follow-up plan after the event.
**Stage:** any stage where buyers gather at events.
**Time box:** start 6-8 weeks before the event; outreach 2-3 weeks before; follow-up within a week after.

| Step | Skill | Input | Hand-off artifact |
|---|---|---|---|
| 1 | [programmatic-pages](../../programmatic-pages/SKILL.md) (optional) | Official event facts | Event guide page as SEO and outreach asset |
| 2 | [prospect-list-builder](../../prospect-list-builder/SKILL.md) | Official exhibitor list, ICP | Tiered list with event columns and research angles |
| 3 | [offer-design](../../offer-design/SKILL.md) | Event context | Event-specific entry or proof offer |
| 4 | [cold-email](../../cold-email/SKILL.md) + [linkedin-outbound](../../linkedin-outbound/SKILL.md) | Steps 2-3 | Pre-event sequences that reference the event |
| 5 | [linkedin-ads](../../linkedin-ads/SKILL.md) or [google-ads](../../google-ads/SKILL.md) (optional) | Account list, event terms | Air-cover campaign with stop rules |
| 6 | [send-preflight](../../send-preflight/SKILL.md) | Steps 4-5 | Gate table |
| 7 | [revenue-handoff](../../revenue-handoff/SKILL.md) | Replies, booked meetings | Call guides for on-site meetings |
| 8 | [marketing-reporting](../../marketing-reporting/SKILL.md) | Results after the event | Event report: meetings, pipeline, cost, lessons |

**Gates:** official sources for event facts; a company exhibiting does not prove a person attends; [outreach-compliance](../policies/outreach-compliance.md) and [approval-gates](../policies/approval-gates.md) for sends and spend.

**Done when:** post-event follow-ups are sent or scheduled, meetings and pipeline are recorded by stage, and the next event's list of changes exists.
