# Tools by task

Write down the job first, then pick from what you already have. This is a usage and evaluation list: no prices, no guarantee that a plan includes the feature you need, and no claim that any tool performs best.

| Task | Start with / candidates | When it is needed | Check when choosing |
|---|---|---|---|
| Interviews and research | Docs and spreadsheets; recruiting panels such as [User Interviews](https://www.userinterviews.com/) | When you cannot find the right people to talk to | Sample fit, cost, interview consent |
| Customers and pipeline | Your existing CRM; a spreadsheet for very small teams | When follow-ups start slipping between people | Owner, next step, source and status fields |
| On-site and product behaviour | Product analytics and web analytics you already run | When you need to explain usage and drop-off | Business events, identity, environments, deduplication |
| Search data | Search Console; a keyword tool if justified | Once you have content and search questions | Keep your own data apart from tool estimates |
| Website | Your existing site builder or CMS | When pages affect conversion | Forms, update cost, mobile, attribution |
| Account research | Manual research first; sales databases and enrichment tools as candidates | After matching rules are defined by hand | Coverage, accuracy, sources, export rights, cost |
| Technology signals | Technology lookup tools such as [Wappalyzer](https://www.wappalyzer.com/) | When the tech stack relates to the buying job | Detection evidence; never treat it as purchase intent |
| Outbound | A sending tool with warm-up and suppression | After the list and message are validated | Sender health, opt-out handling, logs, permissions |
| Creator partnerships | Manual first; creator marketplaces later | When finding and managing partners by hand gets costly | Audience evidence, fees, delivery, downstream tracking |
| Affiliate management | An affiliate network or partner platform | Once real partner demand exists | Commission, refunds, duplicate attribution, partner activation |
| Static content | Your design tools and templates | For ongoing pages and assets | Templates, asset rights, brand consistency |
| Demo video | Screen recording tools with captions | When buyers need to see the real workflow | Recording speed, captions, privacy, reuse |
| Motion and animation | Your existing motion or video pipeline | When an abstract idea is worth explaining | Review cost, factual accuracy, purpose |
| Automation | Workflow automation and coding agents, evaluated per task | After a process is stable and repeats | Logs, failure recovery, permissions, a maintainer |
| Knowledge base | Markdown in a versioned repository | To keep sources, methods and revisions | Search, versions, internal versus public scope |

The linked sites were checked only for what they do; that supports the task description, not a judgment that they work best. Check your existing accounts and the official documentation before implementing anything.

## Purchase card

Before buying, write: the current problem, how often it happens each week, time spent today, the capability to test, total cost, data handling requirements, an owner and an exit plan. Compare results on one real task before subscribing. Trial data from a vendor is not an authorized contact list.
